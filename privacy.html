Privacy policy

Last updated: 22 November 2026

Canopy is a personal tool operated by Faiz Khan (contact: faizpathan1717@gmail.com). It is used only by its owner on his own YouTube channels.

What data it uses

With the owner's permission through Google sign-in, Canopy uses the YouTube Data API and YouTube Analytics API to upload and manage videos on the owner's channels and to read those channels' statistics (views, likes, watch time, audience retention, subscribers gained).

How the data is used and stored

The data is used only to publish the owner's videos and to decide which of the owner's videos to make next. It is stored only on the owner's own computer. It is never sold, shared with or transferred to third parties, and is not used for advertising.

Google user data

Canopy's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.

Deletion

The owner can delete all stored data at any time by deleting the tool's local data folder.
